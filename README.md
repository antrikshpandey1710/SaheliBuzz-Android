# SaheliBuzz Android

Native Android application for SaheliBuzz.

## Current phase

This repository starts with a Kotlin + Jetpack Compose native Android foundation.

Planned integration:
- Firebase Authentication
- Firestore realtime feeds/chats
- Firebase Cloud Messaging notifications
- Cloudinary media uploads
- Native feed, profiles, stories, chats and notifications
- GitHub Actions APK builds

The original `SaheliBuzz` web repository and the old `SaheliBuzz-apk` repository are intentionally kept separate.
